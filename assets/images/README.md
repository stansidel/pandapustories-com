# Images

Drop your images here using these names. Any that are missing are replaced by
text or a paper-coloured placeholder, so the site always works.

| File | Used for | Suggested size |
|---|---|---|
| `logo.png` | "Panda Pu" title artwork on the home page | about 1200 px wide, transparent background |
| `og-image.jpg` | Picture shown when the site is shared on social media or in messages | 1200 × 630 px |
| `covers/panda-pu-learns-to-draw.jpg` | Book cover (one per book; the path is set in the book's Markdown file) | about 1000 px wide |
| `decorations/coming-soon.png` | Optional small drawing by "More stories are coming" on the home page | about 400 px wide |
| `decorations/footer.png` | Optional small drawing above the footer | about 300 px wide |

Use JPG, PNG or WebP. To use a different file name, change the path in
`hugo.toml` (logo, share image, footer), `content/_index.md` (coming-soon
drawing) or the book's Markdown file (cover).
